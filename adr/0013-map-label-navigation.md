# 表示中の地名から移動し、価格データの選択を優先する

- 日付: 2026-09-14
- 状態: 採用

## 背景

地図上で見えている駅や自治体を起点に探索したい。駅名は価格より手前に描画されるため、地名のクリックをそのまま追加すると、価格の点・棒を選ぶ操作と競合する。また、サイドバーを畳んで地図を広くしたときにもデータ種別は切り替えたい。

## 決定と理由

クリックは既存の価格のヒット判定を先に実行し、選択できた場合は地名を処理しない。3Dでは描画中の棒、ポイント・ヒート表示では価格の点を優先する。地名はMapLibreの描画済みsymbolのヒット判定を使い、表示中の駅・都道府県・市区町村ラベルだけを移動の入口にする。価格の手前に駅名を描画する[ADR 0006](0006-station-label-priority.md)は維持する。

移動先は既存の地図データが持つラベルの座標とし、外部検索APIや行政区域の追加取得を使わない。名称と地図の分類で都道府県・市町村・区・駅を判別し、種類に応じた縮尺へ移動する。東京都のように背景地図がcityに分類する都道府県名も考慮する。駅は周辺地域も見渡せる縮尺へ揃え、拡大中の場合も引いて表示する。自治体はすでに十分拡大している場合、現在の縮尺を保つ。方角と傾きも維持し、OSの視差効果を減らす設定では移動アニメーションを省く。

サイドバー上部の同じボタンで詳細設定を開閉する。PCの折りたたみ時には縦のメニュー、狭い画面では地図上部の小さな横メニューを残す。表示面積を確保しながら、アイコンと名称、選択色でデータを切り替えられる。表示指標・用途・年の設定は開閉で保持する。[対象年の選択方針](0010-sidebar-year-selection.md)は維持する。

マウスを重ねたときはクリックと同じ優先順位で対象を判定し、地名の文字色と縁取り、価格の点のリング、棒の既存ハイライトで選択可能な対象を示す。操作を説明する文言やツールチップは表示しない。背景地図のfeature IDと価格データのIDを使い、同名の別地点をまとめて強調しない。文字の配置や衝突判定を変えず、MapLibreのfeature-stateで描画だけを変更する。地図移動・データ更新・表示方法の変更・マウス離脱・クリック時にはハイライトを解除し、古い対象が残らないようにする。

## 代替案とトレードオフ

地名をクリックするたびにジオコーディングする方式は、表示中の地点と同名の別地域への誤移動や、通信待ちを招く。行政境界を別途取得して全域を収める方式は、区域ごとに正確な範囲を表示できる一方、追加データの取得・管理が必要になる。今回はラベルの代表点へ移動するため、都道府県・自治体の全域を画面に収めることは保証しない。表示されないラベルを名前だけで選択する機能は追加しない。

折りたたみ時にすべての条件を残すと地図の表示領域を圧迫するため、詳細な条件はパネルを開いて変更する。選択中の指標・用途・年は折りたたみ中には表示しない。

## 見直す条件

自治体全域の比較や区域単位の選択が必要になった場合は行政境界を使う方式を検討する。背景地図の分類や駅レイヤー構成を変更する際には、地名の対象判定と重なりの回帰テストを確認する。
